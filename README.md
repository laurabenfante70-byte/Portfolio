# Portfolio LB

Sito statico per GitHub Pages. Nessuna build necessaria.

## Pubblicazione
1. Crea un repository su GitHub e carica **il contenuto** di questa cartella (index.html, assets, .nojekyll) nella radice.
2. Vai in Settings > Pages > Build and deployment.
3. In Source scegli "Deploy from a branch", branch `main`, cartella `/ (root)`, poi Save.
4. Dopo circa un minuto il sito è online su `https://TUO-UTENTE.github.io/NOME-REPOSITORY/`.
